How it works

    
    
      
  1. Your code asks typed questions: pick one option, place it on a scale, yes or no.
    2. 
      
  2. The decision model answers with a probability for every option. The LLM gets the same questions in a prompt and writes JSON.
    3. 
      
  3. Your code decides what happens: thresholds, policies, escalation when confidence is low. The model never runs free.
    4. 
    

    
Both models run on Microsoft Foundry. Latency is the model round trip measured on the server; the big clocks are wall time in your browser. The LLM gets a clear JSON answer format, runs with reasoning effort none (its fastest setting) and at most 300 output tokens per call. Limits: 10 live runs per minute per visitor, 500 model calls per day.
